# Лабораторийн ажил №1 – Playwright ашиглан UI автомат тест хийх

## 1. Төслийн танилцуулга

Энэхүү төсөл нь **Playwright** болон **TypeScript** ашиглан веб програмын хэрэглэгчийн интерфэйсийг автоматжуулан тестлэх (End-to-End буюу E2E Testing) үйл явцыг харуулна.

Тестийг [SauceDemo](https://www.saucedemo.com/) демо веб аппликейшн дээр гүйцэтгэнэ.

Энэхүү лабораторийн ажлын гол зорилго нь браузерын автоматжуулалтыг ойлгох, автомат тестийн тохиолдлууд үүсгэх, веб элементүүдтэй харилцах, програмын үйл ажиллагааг шалгах болон тестийн тайлан гаргаж авахад оршино.

## 2. Ашигласан технологиуд

- **Node.js** – JavaScript ажиллуулах орчин (18 болон түүнээс дээш хувилбар)
- **Playwright** – Веб автоматжуулалтын тестийн хэрэгсэл
- **TypeScript** – Тест бичихэд ашигласан програмчлалын хэл
- **Visual Studio Code** – Код бичих редактор
- **SauceDemo** – Тест хийх демо веб аппликейшн
- **Git болон GitHub** – Кодын хувилбарын удирдлага болон эх код хадгалах платформ

## 3. Тестийн орчин

**Веб аппликейшний хаяг:** https://www.saucedemo.com/

**Тестийн хэрэглэгчийн мэдээлэл:**

| Талбар | Утга |
|---|---|
| Хэрэглэгчийн нэр | `standard_user` |
| Нууц үг | `secret_sauce` |

**Тест хийсэн браузерууд:**
- Chromium
- Firefox
- WebKit

## 4. Тестийн тохиолдлууд

Энэхүү төсөлд дараах автомат тестүүдийг хэрэгжүүлсэн.

### Тест 1: Системд амжилттай нэвтрэх

**Зорилго:** Зөв хэрэглэгчийн мэдээлэл ашиглан системд амжилттай нэвтэрч болох эсэхийг шалгах.

**Алхамууд:**
1. SauceDemo веб сайтыг нээнэ.
2. `standard_user` хэрэглэгчийн нэрийг оруулна.
3. `secret_sauce` нууц үгийг оруулна.
4. Login товчийг дарна.
5. Products хуудас гарч ирсэн эсэхийг шалгана.
6. URL хаягт `inventory.html` байгаа эсэхийг шалгана.
7. Системээс гарна.

**Хүлээгдэж буй үр дүн:** Хэрэглэгч системд амжилттай нэвтэрч Products хуудас руу шилжинэ. Logout хийсний дараа нэвтрэх хуудас руу буцна.

### Тест 2: Буруу мэдээллээр нэвтрэх

**Зорилго:** Буруу хэрэглэгчийн мэдээлэл оруулах үед систем алдааны мэдэгдэл харуулж байгаа эсэхийг шалгах.

**Алхамууд:**
1. SauceDemo веб сайтыг нээнэ.
2. Зөв хэрэглэгчийн нэрийг оруулна.
3. Буруу нууц үг оруулна.
4. Login товчийг дарна.
5. Алдааны мэдэгдэл гарч ирсэн эсэхийг шалгана.
6. Хэрэглэгч нэвтрэх хуудсандаа хэвээр байгаа эсэхийг шалгана.

**Хүлээгдэж буй үр дүн:** Систем нэвтрэлтийн алдааны мэдэгдэл харуулж, хэрэглэгчийг системд нэвтрүүлэхгүй.

### Тест 3: Барааг сагсанд нэмэх

**Зорилго:** Хэрэглэгч барааг худалдааны сагсанд амжилттай нэмж чадаж байгаа эсэхийг шалгах.

**Алхамууд:**
1. Зөв хэрэглэгчийн мэдээллээр системд нэвтэрнэ.
2. Sauce Labs Backpack барааг олно.
3. Add to cart товчийг дарна.
4. Товч Remove болж өөрчлөгдсөн эсэхийг шалгана.
5. Сагсны тэмдэглэгээнд `1` гэсэн тоо гарсан эсэхийг шалгана.
6. Худалдааны сагсыг нээнэ.
7. Sauce Labs Backpack бараа сагсанд байгаа эсэхийг шалгана.
8. Системээс гарна.

**Хүлээгдэж буй үр дүн:** Сонгосон бараа сагсанд амжилттай нэмэгдэж, сагсны хуудсанд харагдана.

## 5. Ашигласан Playwright боломжууд

Энэхүү төсөлд Playwright-ийн дараах боломжуудыг ашигласан.

- `test()` – Автомат тестийн тохиолдол тодорхойлох.
- `expect()` – Програмын хүлээгдэж буй үр дүнг шалгах.
- `page.goto()` – Веб хуудасны хаяг руу шилжих.
- `getByRole()` – Элементийг хүртээмжийн үүрэг болон нэрээр нь олох.
- `getByPlaceholder()` – Оруулах талбарыг placeholder текстээр нь олох.
- `locator()` – CSS selector болон тестийн атрибутаар элемент олох.
- `fill()` – Оруулах талбарт текст бичих.
- `click()` – Элемент дээр дарах.
- `toBeVisible()` – Элемент харагдаж байгаа эсэхийг шалгах.
- `toHaveURL()` – Одоогийн хуудасны URL хаягийг шалгах.
- `toHaveText()` – Элементийн текстийг шалгах.

Тестийн кодыг илүү ойлгомжтой, засварлахад хялбар байлгахын тулд Playwright-ийн орчин үеийн locator-уудыг ашигласан. XPath selector ашиглахаас зайлсхийсэн.

## 6. Тестүүдийн тусгаарлалт (Test Isolation)

Тест бүр Playwright-ийн `page` fixture ашигладаг. Playwright нь тест бүрд тусгаарлагдсан браузерын орчин үүсгэдэг тул нэг тестийн өгөгдөл болон браузерын төлөв бусад тестэд нөлөөлөхөөс сэргийлдэг.

Мөн амжилттай нэвтрэх болон сагсанд бараа нэмэх тестүүдийн дараа системээс гарах үйлдлийг оруулсан.

## 7. Тест ажиллуулах

Эхлээд төслийн шаардлагатай сангуудыг суулгана.

```bash
npm install
```

Playwright-ийн браузеруудыг суулгана.

```bash
npx playwright install
```

Бүх тестийг ажиллуулах:

```bash
npx playwright test
```

Зөвхөн Chromium дээр тест ажиллуулах:

```bash
npx playwright test --project=chromium
```

Браузерыг нүдээр харах горимд тест ажиллуулах:

```bash
npx playwright test --headed
```

## 9. HTML тестийн тайлан

Тестүүдийг ажиллуулсны дараа HTML тайланг нээхийн тулд дараах командыг ашиглана.

```bash
npx playwright show-report
```

HTML тайланд дараах мэдээллүүд харагдана:

- Нийт тестийн тоо
- Амжилттай тестүүд
- Амжилтгүй тестүүд
- Тест ажилласан хугацаа
- Алдааны мэдээлэл болон тестийн дэлгэрэнгүй мэдээлэл

Playwright нь тестийн тайланг автоматаар үүсгэдэг бөгөөд үүнийг тестийн үр дүнг шинжлэхэд ашиглаж болно.

## 9. Playwright Codegen

Playwright Codegen нь браузер дээр хийсэн үйлдлүүдийг бичиж авч, автомат тестийн код үүсгэхэд ашиглагдана.

Дараах командыг ажиллуулна.

```bash
npx playwright codegen https://www.saucedemo.com/
```

Codegen нь браузер нээж, хэрэглэгчийн хийж буй үйлдлүүдийг бүртгэнэ. Жишээлбэл, оруулах талбарт текст бичих, товч дарах зэрэг үйлдлүүдийг Playwright код болгон санал болгодог.

Энэ боломж нь эхлэн суралцагчдад автомат тестийн код бичих арга барилыг ойлгоход тусалдаг.

## 10. Playwright Trace Viewer

Trace Viewer нь тестийн ажилласан үйл явцыг нарийвчлан шалгах болон алдааг илрүүлэхэд ашиглагдана.

Trace бичлэгтэйгээр тест ажиллуулах:

```bash
npx playwright test --trace on
```

Бичигдсэн trace файлыг нээх:

```bash
npx playwright show-trace test-results/<test-folder>/trace.zip
```

Trace Viewer дараах боломжуудтай:

- Тестийн алхам бүрийн гүйцэтгэлийг харах
- Дэлгэцийн зураг харах
- DOM бүтцийн хуулбарыг харах
- Сүлжээний үйл ажиллагааг шалгах
- Алдааны мэдээллийг харах

Эдгээр боломжууд нь тест яагаад амжилтгүй болсныг тодорхойлоход тусалдаг.

## 11. Playwright болон Selenium-ийн харьцуулалт

Playwright болон Selenium нь веб браузерын автомат тест хийхэд өргөн ашиглагддаг хэрэгслүүд юм. Гэхдээ эдгээр нь хэд хэдэн чухал ялгаатай.

1. Playwright нь Microsoft-ийн хөгжүүлсэн орчин үеийн автоматжуулалтын хэрэгсэл бол Selenium нь олон жилийн турш ашиглагдаж ирсэн Browser Automation хэрэгсэл юм.
2. Playwright нь Chromium, Firefox болон WebKit браузеруудыг дэмждэг. Харин Selenium нь WebDriver хэрэгжүүлэлтээр дамжуулан олон төрлийн браузерыг дэмждэг.
3. Playwright нь элементүүдийг автоматаар хүлээх боломжтой тул тестийн хугацаатай холбоотой алдааг багасгадаг. Selenium-д ихэвчлэн хөгжүүлэгчид хүлээлтийн тохиргоог өөрсдөө хийх шаардлагатай.
4. Playwright нь дэлгэцийн зураг авах, видео бичлэг хийх, Trace Viewer ашиглах зэрэг боломжуудыг өөртөө агуулдаг. Selenium-д ижил боломжуудыг ашиглахын тулд нэмэлт хэрэгсэл эсвэл сан шаардлагатай байдаг.
5. Playwright нь олон браузерын context үүсгэх боломжтой тул тестүүдийг хооронд нь тусгаарлахад хялбар.
6. Playwright нь браузерын үйлдлүүдийг бичиж авч тестийн код үүсгэх Codegen боломжтой.
7. Selenium нь Java, Python, C# болон JavaScript зэрэг олон програмчлалын хэлийг дэмждэг. Playwright мөн TypeScript, JavaScript, Python, Java болон .NET зэрэг хэлийг дэмждэг.
8. Playwright нь автоматаар хүлээх болон өөртөө багтаасан хэрэгслүүдийн ачаар орчин үеийн E2E тестэд ашиглахад тохиромжтой. Харин Selenium нь өмнө нь үүссэн автоматжуулалтын төслүүд болон өргөн экосистем шаарддаг орчинд хэрэгтэй хэвээр байна.

**Дүгнэлт:** Хоёр хэрэгсэл хоёулаа UI автомат тест хийхэд үр дүнтэй. Энэхүү лабораторийн ажилд Playwright-ийг сонгосон нь орчин үеийн locator, автомат хүлээлт, браузерын дэмжлэг болон алдаа оношлох нэмэлт хэрэгслүүдтэй холбоотой.

## 12. Дүгнэлт

Энэхүү лабораторийн ажлын хүрээнд би Playwright болон TypeScript ашиглан веб интерфэйсийн автомат тестийн төсөл боловсруулсан. SauceDemo веб аппликейшн дээр амжилттай нэвтрэх, буруу мэдээллээр нэвтрэх болон барааг худалдааны сагсанд нэмэх тестүүдийг хэрэгжүүлсэн.

Мөн Playwright-ийн орчин үеийн locator, assertion, браузерын автоматжуулалт болон тестийн тусгаарлалтын талаар дадлага хийсэн. Үүнээс гадна тестийн код үүсгэх Codegen, HTML тайлан болон алдаа оношлох Trace Viewer хэрэгслүүдтэй танилцсан.

Энэхүү лабораторийн ажлын үр дүнд би веб програмын End-to-End тест хийх практик туршлага хуримтлуулж, Playwright болон Selenium-ийн ялгааг ойлгож авсан.
