# Лабораторийн ажил №1 – Playwright ашиглан UI автомат тест хийх

- **Оюутны нэр:** Э.Цэгмид
- **Оюутны код:** B232270107
- **Хичээлийн код:** F.CSA313

## 1. Төслийн танилцуулга

Энэхүү лабораторийн ажлын хүрээнд Playwright болон TypeScript ашиглан веб програмын хэрэглэгчийн интерфэйсийг автоматжуулан тестлэх (End-to-End буюу E2E Testing) төсөл боловсруулсан.

Тестийг [SauceDemo](https://www.saucedemo.com/) демо веб аппликейшн дээр гүйцэтгэнэ.

Төслийн гол зорилго нь браузерын автоматжуулалтыг ойлгох, тестийн тохиолдол боловсруулах, веб элементүүдтэй харилцах, програмын үйл ажиллагааг шалгах болон тестийн тайлан гаргаж авахад оршино.

## 2. Ашигласан технологиуд

- **Node.js 20+** – JavaScript ажиллуулах орчин
- **Playwright 1.65.1** – Веб автоматжуулалтын тестийн хэрэгсэл
- **TypeScript** – Тест бичихэд ашигласан програмчлалын хэл
- **Visual Studio Code** – Код бичих редактор
- **SauceDemo** – Тест хийх демо веб аппликейшн
- **Git болон GitHub** – Эх кодын хувилбарын удирдлага, хадгалалт

## 3. Тестийн орчин

**Веб аппликейшний хаяг:** https://www.saucedemo.com/

**Тестийн хэрэглэгчийн мэдээлэл:**

| Талбар | Утга |
|---|---|
| Хэрэглэгчийн нэр | `standard_user` |
| Нууц үг | `secret_sauce` |

Тестүүдийг Playwright-ийн `page` fixture ашиглан тусгаарлагдсан браузерын орчинд ажиллуулна.

## 4. Хэрэгжүүлсэн тестийн тохиолдлууд

### Тест 1: Системд амжилттай нэвтрэх

**Зорилго:** Зөв хэрэглэгчийн мэдээлэл ашиглан системд амжилттай нэвтэрч болох эсэхийг шалгах.

**Алхамууд:**
1. SauceDemo веб сайтыг нээнэ.
2. `standard_user` хэрэглэгчийн нэрийг оруулна.
3. `secret_sauce` нууц үгийг оруулна.
4. Login товчийг дарна.
5. Products хуудас гарч ирсэн эсэхийг шалгана.
6. URL хаягт `inventory.html` байгаа эсэхийг шалгана.
7. Системээс Logout хийнэ.

**Хүлээгдэж буй үр дүн:** Хэрэглэгч амжилттай нэвтэрч Products хуудас руу шилжинэ. Logout хийсний дараа Login хуудас руу буцна.

### Тест 2: Буруу мэдээллээр нэвтрэх

**Зорилго:** Буруу нууц үг оруулах үед систем алдааны мэдэгдэл харуулж байгаа эсэхийг шалгах.

**Алхамууд:**
1. SauceDemo веб сайтыг нээнэ.
2. Зөв хэрэглэгчийн нэрийг оруулна.
3. Буруу нууц үг оруулна.
4. Login товчийг дарна.
5. Алдааны мэдэгдэл гарч ирсэн эсэхийг шалгана.
6. Хэрэглэгч Login хуудас дээр хэвээр байгаа эсэхийг шалгана.

**Хүлээгдэж буй үр дүн:** Систем алдааны мэдэгдэл харуулж, хэрэглэгчийг нэвтрүүлэхгүй.

### Тест 3: Барааг сагсанд нэмэх

**Зорилго:** Хэрэглэгч барааг худалдааны сагсанд амжилттай нэмж чадаж байгаа эсэхийг шалгах.

**Алхамууд:**
1. Зөв хэрэглэгчийн мэдээллээр системд нэвтэрнэ.
2. Sauce Labs Backpack барааг олно.
3. Add to cart товчийг дарна.
4. Товч Remove болж өөрчлөгдсөн эсэхийг шалгана.
5. Сагсны тэмдэглэгээнд `1` гэсэн тоо гарсан эсэхийг шалгана.
6. Худалдааны сагсыг нээнэ.
7. Sauce Labs Backpack бараа сагсанд байгаа эсэхийг шалгана.
8. Системээс Logout хийнэ.

**Хүлээгдэж буй үр дүн:** Сонгосон бараа сагсанд амжилттай нэмэгдэж, сагсны хуудсанд харагдана.

## 5. Ашигласан Playwright боломжууд

Энэхүү төсөлд Playwright-ийн дараах боломжуудыг ашигласан.

- `test()` – Автомат тестийн тохиолдол тодорхойлох.
- `expect()` – Хүлээгдэж буй үр дүнг шалгах.
- `page.goto()` – Веб хуудасны хаяг руу шилжих.
- `getByRole()` – Элементийг accessibility role болон нэрээр нь олох.
- `getByPlaceholder()` – Оруулах талбарыг placeholder текстээр нь олох.
- `locator()` – CSS selector болон test attribute ашиглан элемент олох.
- `fill()` – Оруулах талбарт текст бичих.
- `click()` – Элемент дээр дарах.
- `toBeVisible()` – Элемент харагдаж байгаа эсэхийг шалгах.
- `toHaveURL()` – Одоогийн URL хаягийг шалгах.
- `toHaveText()` – Элементийн текстийг шалгах.
- `toContainText()` – Элементийн текстэд тодорхой утга байгаа эсэхийг шалгах.

Тестийн кодыг ойлгомжтой, дахин ашиглах боломжтой байлгахын тулд `login()` болон `logout()` туслах функцуудыг ашигласан. Мөн XPath selector ашиглахаас зайлсхийж, Playwright-ийн locator-уудыг ашигласан.

## 6. Тестүүдийн тусгаарлалт (Test Isolation)

Тест бүр Playwright-ийн `page` fixture ашигладаг. Playwright нь тест бүрд тусгаарлагдсан browser context болон page үүсгэдэг тул нэг тестийн браузерын төлөв нөгөө тестэд нөлөөлөхөөс сэргийлдэг.

Амжилттай нэвтрэх болон сагсанд бараа нэмэх тестүүдийн төгсгөлд системээс гарах үйлдлийг оруулсан.

Ингэснээр тестүүдийг бие даан ажиллуулах боломжтой бөгөөд өмнөх тестийн нэвтрэлтийн төлөвөөс хамаарахгүй.

## 7. Тест ажиллуулах заавар

### 7.1. Шаардлагатай сангуудыг суулгах

```bash
npm install
```

### 7.2. Playwright браузеруудыг суулгах

```bash
npx playwright install
```

### 7.3. Бүх тестийг ажиллуулах

```bash
npx playwright test
```

### 7.4. Тестийг браузер нүдээр харах горимд ажиллуулах

```bash
npx playwright test --headed
```

### 7.5. HTML тайлан үүсгэн тест ажиллуулах

```bash
npx playwright test --reporter=html
```

### 7.6. HTML тайланг нээх

```bash
npx playwright show-report
```

## 8. HTML тестийн тайлан

Playwright-ийн HTML Reporter нь тестийн үр дүнг дэлгэрэнгүй харуулах боломжтой.

Тайланд дараах мэдээллүүд багтана:

- Нийт тестийн тоо
- Амжилттай тестүүд
- Амжилтгүй тестүүд
- Тест ажилласан хугацаа
- Алдааны мэдээлэл болон тестийн дэлгэрэнгүй алхмууд

HTML тайланг үүсгэхийн тулд:

```bash
npx playwright test --reporter=html
```

Үүссэн тайланг нээхдээ:

```bash
npx playwright show-report
```

HTML тайлан нь төслийн `playwright-report/` хавтсанд үүснэ.

## 9. Playwright Codegen

Playwright Codegen нь браузер дээр хийсэн хэрэглэгчийн үйлдлүүдийг бичиж авч, автомат тестийн код үүсгэхэд ашиглагддаг хэрэгсэл юм.

Дараах командыг ажиллуулна:

```bash
npx playwright codegen https://www.saucedemo.com/
```

Codegen нь браузер нээж, хэрэглэгчийн хийж буй үйлдлүүдийг бүртгэнэ. Жишээлбэл, текст оруулах, товч дарах болон хуудас хооронд шилжих үйлдлүүдийг Playwright код болгон харуулна.

Энэ боломж нь автомат тестийн код бичих арга барилыг ойлгоход тусалдаг.

## 10. Playwright Trace Viewer

Trace Viewer нь тестийн ажилласан үйл явцыг нарийвчлан шалгах, алдааг илрүүлэхэд ашиглагддаг хэрэгсэл юм.

Trace бичлэгтэйгээр тест ажиллуулах:

```bash
npx playwright test --trace on
```

Бичигдсэн trace файлыг нээх:

```bash
npx playwright show-trace test-results/<test-folder>/trace.zip
```

Trace Viewer дараах боломжуудтай:

- Тестийн алхам бүрийн гүйцэтгэлийг харах
- Дэлгэцийн зураг харах
- DOM бүтцийг шалгах
- Сүлжээний үйл ажиллагааг шалгах
- Алдааны мэдээллийг харах

Эдгээр боломжууд нь тест яагаад амжилтгүй болсныг тодорхойлоход тусалдаг.

## 11. Playwright болон Selenium-ийн харьцуулалт

Playwright болон Selenium нь веб браузерын автомат тест хийхэд өргөн ашиглагддаг хэрэгслүүд юм. Гэхдээ эдгээр нь хэд хэдэн чухал ялгаатай.

1. Playwright нь Microsoft-ийн хөгжүүлсэн орчин үеийн автоматжуулалтын хэрэгсэл бол Selenium нь олон жилийн турш ашиглагдаж ирсэн Browser Automation хэрэгсэл юм.
2. Playwright нь Chromium, Firefox болон WebKit браузеруудыг дэмждэг. Харин Selenium нь WebDriver хэрэгжүүлэлтээр дамжуулан олон төрлийн браузерыг дэмждэг.
3. Playwright нь элементүүдийг автоматаар хүлээх боломжтой тул тестийн хугацаатай холбоотой алдааг багасгадаг. Selenium-д зарим тохиолдолд хөгжүүлэгчид хүлээлтийн тохиргоог өөрсдөө хийх шаардлагатай.
4. Playwright нь дэлгэцийн зураг авах, видео бичлэг хийх, Trace Viewer ашиглах зэрэг боломжуудтай. Selenium-д ижил боломжуудыг ашиглахын тулд нэмэлт хэрэгсэл шаардлагатай байж болно.
5. Playwright нь browser context ашиглан тестүүдийг тусгаарлах боломжтой.
6. Playwright нь браузерын үйлдлүүдийг бичиж авч тестийн код үүсгэх Codegen боломжтой.
7. Selenium нь Java, Python, C# болон JavaScript зэрэг олон програмчлалын хэлийг дэмждэг. Playwright мөн TypeScript, JavaScript, Python, Java болон .NET зэрэг хэлийг дэмждэг.
8. Playwright нь автоматаар хүлээх болон өөртөө багтаасан хэрэгслүүдийн ачаар орчин үеийн E2E тестэд ашиглахад тохиромжтой. Харин Selenium нь өргөн экосистем болон өмнө нь үүссэн автоматжуулалтын төслүүдэд ашиглагдсаар байна.

**Дүгнэлт:** Хоёр хэрэгсэл хоёулаа UI автомат тест хийхэд үр дүнтэй. Энэхүү лабораторийн ажилд Playwright-ийг сонгосон нь орчин үеийн locator, автомат хүлээлт, браузерын дэмжлэг болон алдаа оношлох нэмэлт хэрэгслүүдтэй холбоотой.

## 12. Дүгнэлт

Энэхүү лабораторийн ажлын хүрээнд Playwright болон TypeScript ашиглан веб интерфэйсийн автомат тестийн төсөл боловсрууллаа.

SauceDemo веб аппликейшн дээр амжилттай нэвтрэх, буруу мэдээллээр нэвтрэх болон барааг худалдааны сагсанд нэмэх гэсэн гурван тестийн тохиолдлыг хэрэгжүүлсэн.

Мөн Playwright-ийн locator, assertion, test isolation, Codegen, Trace Viewer болон HTML Reporter зэрэг боломжуудтай танилцаж, ашиглах арга барилыг судалсан.

Энэхүү ажлын үр дүнд веб програмын үндсэн үйлдлүүдийг автомат тестээр шалгах, тестийн үр дүнг тайлангаар гаргах болон алдааг оношлох анхан шатны мэдлэг эзэмшсэн.
